## Prueba manual que realizará el usuario

1. Abrir Productos en Angular/Electron como administrador y crear RTX 4060 Gaming OC, SKU GPU-4060-001, categoría Tarjetas gráficas, marca Gigabyte, compra 1200, venta 1499, stock inicial 5, mínimo 2, activo. Elegir manualmente una imagen de la biblioteca y guardar. Opcionalmente marcar Destacado dentro de Contenido de la tienda web.
2. Recargar /productos en Astro: debe existir un solo producto en el catálogo. La misma entidad puede aparecer en destacados y novedades del Inicio, pero no se duplican registros.
3. Para cambiar existencias usar **Inventario**: registrar salida de 3 para pasar de 5 a 2 y salida de 2 para llegar a 0. El formulario de editar Producto conserva el control de movimientos existente; no permite editar el stock directamente. Recargar Astro después de cada operación.
4. Editar precio de venta a 1399; recargar catálogo y detalle. Los documentos y consultas no cachean productos.
5. Reemplazar imagen desde Productos, guardar y recargar Astro. El backend genera un nombre UUID nuevo; el navegador puede cachear cada archivo immutable sin reutilizar el anterior. Eliminar la imagen y recargar: se muestra un icono/placeholder genérico, nunca otro producto.
6. La creación con imagen usa POST /api/productos y la edición usa PUT /api/productos/{id}, con multipart/form-data (partes producto e imagen), JWT y rol interno. Para eliminarla, la edición envía eliminarImagen=true. Spring Boot guarda el archivo en uploads/productos y PostgreSQL conserva la ruta. La API pública devuelve imagenUrl; Astro sirve /media/{UUID.ext}?w=320|640|960 consultando GET /api/productos/imagenes/{archivo} al backend. Ambas bibliotecas están fuera del directorio público y sus URLs directas devuelven 404.

La creación y modificaciones reales del primer producto quedan para el usuario, como pidió. No se presentan los tests con respuestas controladas como sustituto de esa prueba manual. Los tests de precio/stock/imagen verifican que cada nueva consulta usa la respuesta actual; no insertan productos en la base habitual.
