# Biblioteca manual de imágenes tecnológicas

**56 ilustraciones originales** en WEBP, máximo 1000 px y cada archivo menor de 2 MB, compatibles con los límites del upload actual. Fondo neutro, producto completo, sin precios ni banners. Además se incluye CONTACT-SHEET.webp como índice visual; no es una imagen de producto.

Esta carpeta está fuera de Web/frontend y no se publica ni se importa desde Astro. No genera productos, categorías, marcas, precios o stock. Para usar una imagen: seleccionarla manualmente en Productos de Angular/Electron, guardar el producto y recargar la tienda.

## Fuente y límites de uso

Todos los archivos se generaron con la herramienta integrada imagegen, con un prompt independiente por imagen y sin referencias fotográficas de terceros. No se descargaron fotos de CGS Computer, otras tiendas o fabricantes; no se presenta este material como fotografía oficial ni como recurso con licencia CC0. Son ilustraciones genéricas de referencia producidas mediante IA, que pueden contener diferencias técnicas respecto de un producto real. No se garantiza identidad con modelos o marcas ni una licencia otorgada por fabricantes. Antes de usarlas como representación comercial de un modelo concreto, comprueba que reflejen fielmente lo que vendes y los permisos aplicables.

Los prompts exactos, archivo fuente generado, dimensiones y peso de cada WEBP están en PROMPTS.json. El método fue generación integrada, no CLI/API ni descargas. Los PNG originales permanecen en la carpeta de imágenes generadas de Codex; los entregables optimizados se encuentran aquí.
